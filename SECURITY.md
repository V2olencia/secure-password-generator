# Política de segurança

Este é um projeto educacional. Não envie senhas, tokens, chaves ou dados pessoais em uma issue pública.

Se encontrar uma falha no código, descreva apenas os passos mínimos para reproduzi-la, sem usar credenciais reais. Até existir um canal privado de contato no perfil, evite publicar detalhes que exponham terceiros.

## Escopo conhecido

- As senhas ficam em memória durante a execução.
- A área de transferência não é limpa automaticamente.
- Não há armazenamento criptografado nem integração com cofres de senhas.
